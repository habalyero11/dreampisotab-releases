# DreamPisoTab releases

App files (APKs) for DreamPisoTab tablets. Tablets download updates from here automatically.

- Each release holds the signed APK, its SHA-256 checksum and short notes in English and Filipino.
- Tablets install an update only if the checksum **and** the signing certificate match, so a changed file is refused.
- The APK works only on tablets with a DreamPisoTab licence.

The source code is not in this repository.
